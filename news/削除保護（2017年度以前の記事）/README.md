# 削除保護（2017年度以前の記事）

このフォルダは、通常の10年度保存ルールを超えて残したい過去記事を保管する場所です。

## 保存方法

1. 残したい年度のフォルダ（例：`news/2016/`）を開きます。
2. フォルダ内の記事を、この「削除保護（2017年度以前の記事）」フォルダの中に、年度ごとのサブフォルダを作って移してください。
   - 例：`news/削除保護（2017年度以前の記事）/2016/`
3. 移動後、元の `news/2016/` は空になったことを確認してから削除してください。

## 削除保護の仕組み

- 自動削除処理は `news/2016/` のような直下の年度フォルダだけを対象にします。
- このフォルダ内に移した記事は自動削除処理の対象外です。
- 保護対象を移動する前に、記事のリンク先や画像パスが壊れないか確認してください。フォルダを移動すると相対リンクが変わる場合があります。
- このフォルダ内のファイルもGitHubリポジトリ上では公開されるため、個人情報や公開許諾のない写真は保存しないでください。

## 注意

フォルダ名の「2017年度以前」は、2026年度時点で通常保存対象となる最古の年度（2017年度）を基準にした表示です。保存対象の境界は年度の経過に応じて見直してください。
