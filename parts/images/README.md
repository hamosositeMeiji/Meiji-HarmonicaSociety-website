# パート紹介画像の置き場

各パート紹介で使う写真をこのフォルダに置きます。現在は仮参照として `BASS-SAMPLE.jpg` を用意しています。

## 画像ファイル名（予定）
- `HARMONICA-SAMPLE.jpg`
- `FLUTE-SAMPLE.jpg`
- `CLARINET-SAMPLE.jpg`
- `KEYBOARD-SAMPLE.jpg`
- `GUITAR-SAMPLE.jpg`
- `BASS-SAMPLE.jpg`
- `PERCUSSION-SAMPLE.jpg`

写真を追加したら、`parts/detail.html` のパート別データに対応する画像パスを指定します。実際の写真を追加するまではサンプル画像の枠を表示します。
